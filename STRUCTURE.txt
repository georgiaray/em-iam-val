EM-IAM-VAL Validation Framework - Complete Restructure
========================================================

CANONICAL FORMAT
All data in the framework uses long-format CSV with columns:
  Model, Scenario, Region, Scenario_Category, Year, Variable, Value, Units

The Units column is populated by adapters and read directly by normalize_to_canonical()
before any checks run.

CANONICAL UNITS
- Energy:     EJ
- CO2:        MtCO2
- CH4:        MtCH4
- N2O:        MtN2O
- CO2eq:      MtCO2eq (Kyoto gases aggregates, not converted)

CHECK REGISTRY (in validate.py)
==============================

2. sum_check                 - Hierarchy sum check

4. bounds_check              - Physical bounds
5. hard_historical_constraints - Hard historical constraints
6. soft_future_constraints   - Soft future constraints

USAGE
=====

Run all checks:
  python validate.py \
    --predictions adapted-data/xgb_04_predictions.csv \
    --ground_truth adapted-data/xgb_04_ground_truth.csv \
    --run_id xgb_04

Run specific checks:
  python validate.py ... --only bounds_check sum_check

Skip specific checks:
  python validate.py ... --skip regional_consistency

Generate predictions CSV from XGBoost model:
  python adapters/xgb_adapter.py --run_id xgb_04 --out_dir adapted-data/

Generate predictions CSV from Li et al. model:
  python adapters/li_adapter.py --model vae --run_id li_vae_01 --out_dir adapted-data/

Run individual check:
  python checks/bounds_check.py \
    --predictions adapted-data/xgb_04_predictions.csv \
    --run_id xgb_04

IMPLEMENTATION NOTES
====================

1. All data is normalized to canonical units ONCE before any checks run
2. Normalization reads Units from each row and converts Value using lookup table
3. Normalization output is printed so users know what was converted
4. Each check normalizes within its run() function for safety (idempotent)
5. Unit plausibility warnings are flagged when median value is >100x off typical
6. All output directories are created by make_out_dir()
7. Ground truth checks save to {check_name}_ground_truth/ subdirectories
8. Return dict always has: check_name, passed, results, summary, unit_warnings, skipped
9. When no relevant variables found: return passed=True, empty DataFrames, clear message
10. Check functions accept **kwargs but use inspect.signature() to filter
